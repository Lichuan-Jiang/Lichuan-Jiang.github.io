Magnetic dipole field simulator

Drag magnet centers to move them. Drag arrow tips to rotate dipole moments.

Formula

For each dipole i, the field at position r is

B(r) = C Σi [ alpha ri(mi · ri) / rhoin+2 - mi / rhoin ],   ri = r - xi,   rhoi = sqrt(|ri|2 + a2)

Physical point dipoles use alpha = 3 and n = 3. The softening a prevents a numerical singularity near a magnet.
